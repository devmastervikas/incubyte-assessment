# String Calculator TDD Kata

## Description

This project implements the String Calculator Kata using Test-Driven Development (TDD) in Node.js.

## Features Implemented

- Empty input returns 0
- Comma-separated number sums
- Newline delimiter support
- Custom delimiter support (e.g. `//;\n1;2`)
- Exception handling for negative numbers

## How to Run

```bash
npm install
npm test
```
